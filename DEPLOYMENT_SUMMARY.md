## 🎯 Quick Start - Deploy in 10 Minutes

### 1️⃣ Prepare Repository (2 min)
```bash
cd dataquest-insurance-brokerage-ai-assistant
git add .
git commit -m "Add Render & Vercel deployment configs"
git push origin main
```

### 2️⃣ Deploy Backend on Render (3 min)
1. Go to https://render.com
2. Click **New** → **Web Service**
3. Connect GitHub repository
4. Auto-detects `render.yaml`
5. Set environment variables (see `DEPLOYMENT_GUIDE.md`)
6. Click **Deploy**
7. **Copy backend URL** (you'll need this)

### 3️⃣ Deploy Frontend on Vercel (3 min)
1. Go to https://vercel.com
2. Click **Add Project**
3. Connect GitHub repository
4. **Set root directory to `front-end`** ← Important!
5. Environment Variables:
   - `NEXT_PUBLIC_API_URL` = Your Render backend URL
6. Click **Deploy**
7. **Copy frontend URL** (for CORS update)

### 4️⃣ Update Backend CORS (1 min)
1. Go to Render dashboard → Backend service
2. Environment → Edit `ALLOWED_ORIGINS`
3. Set to your Vercel frontend URL
4. Redeploy

## 🐛 Common Issues & Quick Fixes

| Issue | Cause | Fix |
|-------|-------|-----|
| CORS error | Backend CORS not updated | Update `ALLOWED_ORIGINS` in Render |
| 404 on routes | Wrong root directory | Set root to `front-end` in Vercel |
| API timeout | Backend not running | Check Render logs, redeploy |
| Build fails | Dependencies issue | Run `npm run build` locally to debug |
| Env vars not read | Missing NEXT_PUBLIC prefix | Ensure vars start with `NEXT_PUBLIC_` |
